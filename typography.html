Basic typographic principles

"... never set the copy in reverse ..." - David Ogilvy

Terms:

  • Base line: line which all letters rest on
  • Mean line/x-height: top line of lowercase characters
  • Cap line: top line of capital letters.
  • Ascender: line above the cap line marking the height limit for elements exceeding the cap line, like serifs.
  • Descender: line below the base line marking the limit for descending elements.
  • Font size: the distance between the base line and the base line of the next line when type is set solid (No extra added space between lines, aka leading).
